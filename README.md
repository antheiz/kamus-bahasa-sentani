## 📝 Deskripsi

Kamus Bahasa Sentani Website adalah platform web yang dikembangkan untuk membantu melestarikan dan mempromosikan bahasa Sentani dari Jayapura, Papua. Website ini menyediakan kosakata bahasa Sentani beserta terjemahan, pengucapan, dan contoh penggunaan dalam kalimat.

## ✨ Fitur Utama

- **Kamus Komprehensif**: Koleksi kata bahasa Sentani dengan arti, pengucapan, dan kelas kata
- **Pencarian Cepat**: Cari kata dengan mudah menggunakan fitur pencarian realtime
- **Navigasi Abjad**: Akses kata-kata berdasarkan awalan huruf
- **Contoh Kalimat**: Setiap kata dilengkapi dengan contoh penggunaan dalam kalimat
- **Klasifikasi Kelas Kata**: Identifikasi jenis kata (nomina, verba, adjektiva, dll)
- **Lirik Lagu**: Koleksi lirik lagu dalam bahasa Sentani
- **Tampilan Responsif**: Desain yang optimal untuk berbagai perangkat
- **Mode Gelap/Terang**: Pilihan tampilan sesuai preferensi pengguna

## 🛠️ Teknologi yang Digunakan

- **Framework**: [Astro](https://astro.build/)
- **Styling**: [TailwindCSS](https://tailwindcss.com/)
- **UI Components**: [shadcn/ui](https://ui.shadcn.com/)
